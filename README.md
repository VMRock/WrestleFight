# WrestleFight

**WrestleFight** is a work-in-progress 3D wrestling game demo made with Unity. Play solo against the CPU, challenge a friend locally, or watch an AI-versus-AI match. The prototype features arcade-style strikes, grapples, finishers, stamina, reversals, and pinfall kickouts.

## Play in the Unity Editor

Open the project with **Unity 6.4.7f1**, open `Assets/OutdoorsScene.unity`, and press **Play**. Press **Enter** or **Space** at the main menu to start.

**Player 1:** `WASD` move · `J` / `Space` strike · `K` heavy attack · `L` grapple · `U` finisher · `Shift` block · `P` pin

The project is a prototype and is still being developed. Features, balance, and presentation may change. A standalone game build is not currently included.
